## [SLIDE 04] 개념 1 — 에이전틱 루프

> Claude Code가 스스로 생각하고, 행동하고, 검증하는 반복 구조

```
[1] 컨텍스트 수집       →   CLAUDE.md, 파일, 도구 결과 수집
         ↑                          ↓
[3] 결과 확인       ←   [2] 작업 수행
    문제 발견 시                실행 계획 수립
    1단계로 복귀                도구 호출
```

**검증 방식 3가지**
- 규칙 기반 피드백 (lint, test)
- 시각적 피드백 (브라우저 렌더링 확인)
- LLM 기반 평가 (스스로 코드 리뷰)

> 핵심: "AI가 혼자 루프를 돌며 완성될 때까지 반복한다"

## [SLIDE 05] 개념 2 — 컨텍스트 윈도우

> Claude가 한 번의 추론에서 참조할 수 있는 토큰 총량

**적재 순서 (위에서부터 먼저 로드)**
```
1. CLAUDE.md          ← 이 프로젝트의 팀 지침
2. 엔터프라이즈 정책
3. 프로젝트 메모리
4. 사용자 메모리
5. 프로젝트 로컬 메모리
```

**관리 전략**

| 전략 | 언제 쓰나 |
|------|---------|
| 컴팩션 | 98% 도달 시 자동 요약 |
| `/clear` | 새 작업 시작 전 초기화 |
| 점진적 공개 | skill로 필요할 때만 로드 |
| 서브에이전트 | 별도 컨텍스트에서 요약 후 반환 |
| 구조화된 메모 | 대규모 마이그레이션·다단계 작업 |

## [SLIDE 06] 개념 3 — settings.json

> 어디에 두느냐에 따라 적용 범위가 달라지는 계층적 설정

**우선순위 (높음 → 낮음)**
```
관리자 설정 (Claude 자체)
  └─ 엔터프라이즈 정책 (인프라 팀)
       └─ 프로젝트 로컬  .claude/settings.local.json  ← 개인 조정
            └─ 프로젝트  .claude/settings.json        ← 팀 공유 ★
                 └─ 사용자  ~/.claude/settings.json   ← 전역 개인
```

**권한 평가 순서**
```
deny → ask → allow
```
`deny`는 다른 모든 규칙보다 항상 먼저 적용됩니다.

**우리 프로젝트 설정 (`settings.json`)**
- `PostToolUse Write` → 파일 저장 시 헤더 주석 자동 삽입
- `PostToolUse Bash` → git commit 감지 시 Notion 자동 기록
- `PreToolUse Bash` → Conventional Commits 형식 검사

## [SLIDE 07] 개념 4 — 체크포인트 & 되감기

> 파일 편집을 자동 추적하는 실행 취소 안전망 (보관 30일)

**사용법**
- ESC 두 번 또는 `/rewind` 입력
- 복구 옵션: 대화만 / 코드만 / 둘 다

**이럴 때 유용해요**
- 시작점 잃지 않고 대체 구현을 탐색할 때
- 잘못된 변경을 원래대로 되돌려야 할 때
- 작동하는 현 상태를 유지하면서 테스트할 때

**주의 — 이건 추적 안 됩니다**
- Bash로 직접 파일 변경 (`echo`, `sed`, `cp` 등)
- 외부 도구·에디터에서 수정한 내용
- Git 워크트리 병렬 작업 중 다른 트리의 변경

> "체크포인트 ≠ 버전 관리. Git을 대체하지 않는다"

## [SLIDE 08] 핵심 기능 한눈에 보기

**CLI 모드 비교**
| 명령어 | 특징 | 적합한 상황 |
|-------|------|------------|
| `claude` | 대화형 | 탐색, 장기 세션 |
| `claude -p "..."` | 비대화형 | 스크립팅, 자동화 |
| `claude -c` | 세션 재개 | 이전 대화 이어하기 |

**유용한 기능**
- `@파일명` → 특정 파일 명시 참조
- Tab 키 → 파일명 자동 완성
- Ctrl+V / 드래그 → 이미지 직접 첨부
- `/rewind` → 체크포인트 되감기

**AI 코드 리뷰 자동화 (package.json)**
```json
"lint:claude": "claude -p '너는 코드 리뷰어야. main 대비 변경 코드를 검토하고 잠재 버그를 찾아줘.'"
```
