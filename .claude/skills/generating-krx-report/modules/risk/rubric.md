# risk — 채점 기준 (해석용 서술)

> **주의:** 점수는 `config/module-registry.yaml` 이 결정한다. 이 문서는 서술일 뿐 채점하지 않는다.
> 7항목 전부 `type: judged` — **Claude 가 등급(0~3)과 evidence_ids 만 제출**하고, 산술은 하지 않는다.
> 모든 항목 `requires_evidence: 1` — 근거 없는 항목은 자동 N/A.
>
> ## ⚠ `inverse_scale: true`
> **등급이 높을수록 위험이 낮다.** 3 = 위험이 낮거나 잘 통제됨, 0 = 위험이 크고 통제되지 않음.
> **N/A(level: null) ≠ 0점.** 확인할 근거가 없는 것은 위험이 큰 것이 아니다.

## 공통 등급 정의 (모든 RSK 항목에 적용)

| 등급 | 의미 |
|------|------|
| 3 | 해당 위험이 구조적으로 낮거나, 근거상 명확히 통제되고 있다 |
| 2 | 위험은 존재하나 관리 가능한 범위이며 선행지표로 추적 가능하다 |
| 1 | 위험이 실적에 영향을 줄 수 있고, 이미 일부 징후가 근거에서 확인된다 |
| 0 | 위험이 크고 투자 논리를 직접 훼손할 수 있으며 완화 수단이 확인되지 않는다 |
| N/A | 이 위험을 판단할 근거 자체가 없다 → `na_reason` 필수. **0점 아님** |

각 항목 서술에는 6요소가 모두 들어가야 한다:
**위험 내용 / 근거(evidence_id + 출처·기준일) / 발생 가능성 / 영향도 / 선행지표 / 투자 논리 훼손 조건**

## RSK-01 · 사업·산업 사이클 위험 (가중치 18)

- 전방 산업의 수요 사이클, 가동률·판가 변동에 실적이 얼마나 노출되는가.
- 근거: 사업보고서 원문(`B-FILING-001`), 분기 실적 변동 지표(영업이익률·매출 YoY 이력).
- 3: 수요가 구조적으로 안정 / 0: 사이클 저점에서 적자 전환 이력, 완화 수단 없음.
- 선행지표 예: 분기 매출 YoY 방향 전환, 재고자산 증가, 가동률 관련 공시.

## RSK-02 · 고객·공급망 집중 위험 (가중치 16)

- 소수 고객·소수 공급처 의존도. 단일 고객 이탈 시 매출 타격 규모.
- 근거: 사업보고서 원문의 고객·매출처 서술. **구조화 API 가 없으므로 원문 문구에 근거해야 한다.**
- 원문에서 확인 불가하면 **N/A + "사업부문·고객 집중도 구조화 데이터 없음"** (낮은 등급 아님).

## RSK-03 · 재무·유동성 위험 (가중치 18)

- hint_metrics: `net_debt_to_equity`, `interest_coverage`, `current_ratio` — **반드시 값을 인용한다.**
- 3: 순현금 상태(net_debt ≤ 0), 이자보상배율 충분 / 0: 순차입금/자기자본 1.0배 초과 +
  이자보상배율 낮음 + 유동비율 100% 미만.
- 지표가 N/A 면 그 항목은 N/A. 지표 없이 "재무 건전" / "재무 취약" 을 단정하지 않는다.
- 훼손 조건 예: "순차입금/자기자본 1.0배 초과 및 이자보상배율 2배 미만 지속".

## RSK-04 · 회계·일회성 항목 위험 (가중치 12)

- 이익의 질: 영업현금흐름과 순이익의 괴리(`cash_conversion_ttm`), 일회성 손익, 감사의견.
- 근거: 현금전환율 지표, `dart_events.json` 의 손익 관련 공시(손익구조 변동 등).
- 감사의견·주석은 구조화되어 있지 않다 — 확인 근거가 없으면 **N/A**, 추정 금지.

## RSK-05 · 설비투자·희석 위험 (가중치 12)

- hint_metrics: `capex_to_ocf`, `share_change_1y` — 반드시 인용한다.
- 대규모 증설이 FCF 를 잠식하는가. 유상증자·전환사채로 지분이 희석되는가.
- 근거 보강: `dart_events.json` 의 설비투자·자본변동 태그 공시(rcept_no 명시).
- 3: capex 가 영업현금흐름 내에서 감당되고 주식수 변동 미미 / 0: capex_to_ocf 가 1을 크게 넘고
  주식수가 5% 넘게 증가.

## RSK-06 · 밸류에이션·수급 위험 (가중치 12)

- 현재 멀티플에 이미 내재된 기대가 어긋날 때의 하방 위험. 수급 쏠림·거래량 급증의 반대 방향 위험.
- 근거: valuation 지표(PER/PBR/EV/EBITDA), trend 의 `pct_from_52w_high`, `volume_ratio_vs_60d`.
- **KRX 자격증명이 없으면 수급(기관·외국인) 측면은 확인 불가**다. 그 경우 수급 부분을
  unknowns 에 남기고, 밸류에이션 측면만으로 등급을 매기되 신뢰도 한계를 rationale 에 적는다.

## RSK-07 · 규제·환율·원자재 위험 (가중치 12)

- 수출 비중·외화 노출, 주요 원재료 가격, 산업 규제·인증.
- 근거: 사업보고서 원문의 원재료·수출 관련 서술. **거시 전망(환율 예측 등)은 데이터가 없다 — 금지.**
- 원문에 근거가 없으면 N/A. "일반적으로 수출기업은 환율에 민감하다" 같은 일반론으로 등급을 매기지 않는다.

## 데이터 불확실성 = 하나의 위험

- 확인하지 못한 것은 `unknowns` 에 남기고, 그 자체가 판단 신뢰도를 낮춘다는 점을 verdict 에 적는다.
- 예: 수급·시장 국면 미확인(KRX 자격증명 없음), 사업부문별 매출 구조 미확보, 감사 주석 미확인.
- **데이터 부족을 낮은 등급으로 바꾸지 않는다.** N/A + na_reason 이 유일한 처리 방법이다.

## 절대 금지

- 근거 없는 위험 등재 / 뉴스·기억 기반 위험 서술.
- inverse_scale 반대 채점 (위험이 큰데 3등급).
- 확률의 수치화, 거시·환율·업황 전망치 생성.
- 컨센서스·목표주가·시장점유율 인용.
