# CANSLIM 채점 기준 (v1)

각 항목 0~10점. **JSON 수치로만 채점**하고, 데이터 없으면 N/A(점수 부여 금지).
각 항목은 근거 1줄(수치 + 출처·기준일)을 반드시 남긴다.

공통 구간표 (증가율 → 점수):

| 증가율 구간 | 점수 |
|-------------|------|
| ≥ 100%      | 10   |
| 50 ~ 100%   | 8~9  |
| 25 ~ 50%    | 6~7  |
| 10 ~ 25%    | 4~5  |
| 0 ~ 10%     | 2~3  |
| 음수(<0%)   | 0~1  |

---

## C — Current Quarterly Earnings (최근 분기 실적)
- 지표: **최근 분기 영업이익 YoY 증가율** (전년 동기 대비).
  - 데이터: fundamentals.json의 `quarterly[]`에서 최근 분기와 전년 동기 영업이익.
- 위 공통 구간표로 채점.
- **단서**: 전년 동기 영업이익이 음수면 YoY 배율이 왜곡되므로 **상한 8점**으로 캡.
- 전년 동기 데이터가 없으면 → **N/A** (사유: 비교 분기 결측).
- EPS가 있으면 보조 근거로 언급 가능하나 점수는 영업이익 기준.

## A — Annual Earnings (연간 실적 성장성)
- 지표: **최근 3년 영업이익 CAGR** → 공통 구간표로 채점.
  - 데이터: fundamentals.json의 `annual[]` 3개년 영업이익.
  - CAGR = (최근연도/기준연도)^(1/년수) − 1.
- **단서**: 기준연도(가장 과거) 영업이익이 **0 이하이면 CAGR 계산 금지**(음수·허수 방지).
  대신 아래 가점제로 채점하고 **상한 9점**:
  - 흑자 전환(기준연도 ≤0 → 최근연도 >0): +3
  - 3년 연속 개선(매년 전년 대비 증가): +3
  - 전고점 회복(최근연도가 3년 내 최고치): +2
  - 차년 성장(직전연도 대비 최근연도 증가): +2
- 3개년 데이터가 부족하면 → **N/A**.

## S — Supply & Demand (수급/거래량)
- 지표: **60일 평균 대비 최근 거래량 비율** (market.json `volume_ratio_vs_60d`).
- 상대 평가(참고 기준):
  - 비율 ≥ 2.0 → 9~10 / 1.5~2.0 → 7~8 / 1.2~1.5 → 5~6 /
    0.8~1.2 → 3~4 / < 0.8 → 0~2.
- 근거 1줄 필수: "60일 평균比 X.X배 (출처: pykrx, 기준일: ...)".
- 데이터 결측 시 N/A.

## L — Leader or Laggard (주도주 여부)
- 지표: **52주 고점 대비 현재가 근접도** (market.json `pct_from_52w_high`).
  - 근접도 = 현재가 / 52주 고가.
- 상대 평가(참고 기준):
  - 고점 대비 −5% 이내 → 9~10 / −5~−15% → 7~8 / −15~−30% → 5~6 /
    −30~−50% → 3~4 / −50% 미만 → 0~2.
- 근거 1줄 필수. 데이터 결측 시 N/A.

## I — Institutional Sponsorship (기관/외국인 수급)
- 지표: **최근 60일 기관+외국인 순매수 합계** (market.json `inst_foreign_net_60d`).
- 상대 평가(참고 기준, 순매수 방향·강도):
  - 강한 순매수(양수, 시총 대비 큰 유입) → 8~10 /
    완만한 순매수(양수) → 5~7 / 중립(≈0) → 3~4 / 순매도(음수) → 0~2.
- 절대 임계값이 애매하면 방향(양/음)과 값 크기로 판단하고 근거 1줄에 수치를 명시.
- 데이터 결측 시 N/A.

## 채점 종합
- 채점된 항목(N/A 제외)의 점수 합 / (항목 수 × 10) × 100 = 종합 점수(%).
- N/A 항목은 분모·분자에서 제외한다. **0점으로 치지 않는다.**
- 보고서에 "채점 항목 n개 기준"과 각 항목 N/A 사유를 명시한다.
