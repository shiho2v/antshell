# catalyst — 채점 기준 (해석용 서술)

> **주의:** 점수는 `config/module-registry.yaml` 이 결정한다. 이 문서는 서술일 뿐 채점하지 않는다.
> 4항목 전부 `type: judged` — **Claude 가 등급(0~3)과 evidence_ids 만 제출**하고, 산술은 하지 않는다.
> 모든 항목 `requires_evidence: 1`. **N/A(level: null) ≠ 0점.**
>
> ## ⚠ 최우선 규칙
> **공시 근거(rcept_no) 없는 촉매는 등재 자체가 금지된다.**
> 촉매 원천은 `data/raw/{ticker}_dart_events.json` 의 `catalyst_candidates` 뿐이다.
> 뉴스로 촉매를 만들지 않는다 (`news_allowed` 기본 false).

## 촉매 후보의 성격

`catalyst_candidates` 는 공시 **제목 키워드**로 태깅된 목록이다:
`신규수주` / `설비투자` / `자사주` / `지배구조` / `자본변동` / `손익` / `배당`.
evidence_id 는 `C-EVENT-001`, `C-EVENT-002` … 형식이다.

**이 태그는 후보(CANDIDATE)이지 확정된 촉매가 아니다.**
제목만으로 규모·시점·방향을 단정할 수 없다. 채택 여부는 Claude 가 판단하되,
채택하려면 6요소(사건 / 예상 시점 / 재무적 연결 경로 / 확인 지표 / **공시 근거(rcept_no)** /
주가 선반영 가능성)를 모두 채울 수 있어야 한다.

## CAT-01 · 공시로 확인된 촉매의 존재 (가중치 35)

| 등급 | 기준 |
|------|------|
| 3 | 실적에 유의미한 영향이 예상되는 촉매가 **복수의 공시(rcept_no)** 로 확인된다 |
| 2 | 촉매성 사건이 **1건 이상** 공시로 확인되며 성격이 명확하다 |
| 1 | 공시는 있으나 촉매로서의 성격이 약하다 (경상적 사건, 소규모, 성격 불분명) |
| 0 | 공시 목록을 확인했으나 촉매로 볼 만한 사건이 없다 |
| N/A | 공시 데이터 자체를 확보하지 못했다 → `na_reason` 필수 |

- **0 과 N/A 의 구분이 핵심이다.** "공시를 다 봤는데 촉매가 없다" = 0. "공시를 못 봤다" = N/A.
- 정기보고서 제출·단순 정정공시는 촉매가 아니다.

## CAT-02 · 재무적 연결 경로의 명확성 (가중치 30)

| 등급 | 기준 |
|------|------|
| 3 | 촉매 → 매출 → 영업이익 → 현금흐름으로 이어지는 경로가 공시 내용만으로 설명된다 |
| 2 | 경로의 방향(어느 계정에 나타나는가)은 명확하나 규모가 미확인이다 |
| 1 | 경로가 간접적이거나 여러 가정을 거쳐야 한다 |
| 0 | 실적과의 연결이 확인되지 않는다 (예: 지배구조 변경만으로는 손익 경로가 없다) |
| N/A | 등재된 촉매가 없어 경로를 논할 대상이 없다 |

- **규모를 추정하지 않는다.** 공시에 금액이 없으면 "규모 미확인"으로 적고 방향만 서술한다.
- 촉매의 EPS 기여도·주가 상승 여력을 계산하는 것은 금지다.

## CAT-03 · 시점의 구체성과 확인 지표 존재 (가중치 20)

| 등급 | 기준 |
|------|------|
| 3 | 공시에 시점(납기·가동 시점·지급일 등)이 명시되고, 작동 여부를 볼 확인 지표가 특정된다 |
| 2 | 시점이 분기 단위로 특정 가능하고 확인 지표가 있다 |
| 1 | 시점이 모호하나(연내 등) 확인 지표는 존재한다 |
| 0 | 시점도 확인 지표도 특정되지 않는다 |
| N/A | 공시에 시점 정보가 없고 추정이 금지되어 판단 불가 → `na_reason` |

- **공시에 없는 시점을 추정하지 않는다.** "하반기 반영 예상" 같은 서술은 금지다.
- 확인 지표 예: 다음 분기 매출액, 재고자산·유형자산 증감, 후속 공시(공급계약 이행 등).

## CAT-04 · 주가 선반영 여지 (가중치 15) — **inverse**

**`inverse: true` — 이미 선반영되었을수록 낮은 등급이다. 방향을 반대로 매기지 않는다.**

| 등급 | 기준 |
|------|------|
| 3 | 촉매가 최근 공시되었고 주가·거래량에 반응 흔적이 크지 않다 (선반영 여지 낮음) |
| 2 | 부분적으로 반영된 것으로 보이나 여지가 남아 있다 |
| 1 | 공시 이후 주가가 크게 움직였다 — 상당 부분 반영된 것으로 보인다 |
| 0 | 주가가 이미 52주 고점 근접이며 거래량도 급증 — 대부분 반영된 것으로 보인다 |
| N/A | 가격·거래량 데이터 미확보 또는 등재된 촉매 없음 |

- 판단 근거: `pct_from_52w_high`, `volume_ratio_vs_60d`, 공시 접수일과의 시간 관계.
- **"선반영 정도"를 퍼센트로 수치화하지 않는다.** 관측된 사실만 인용해 정성적으로 서술한다.
- 이것은 예측이 아니다. "따라서 추가 상승 여력 x%" 같은 결론은 금지다.

## 촉매가 하나도 없을 때

- CAT-01 = 0 (공시를 확인했고 촉매성 사건이 없음), CAT-02~04 = N/A + `na_reason: "등재된 촉매 없음"`.
- **"촉매 없음"은 정상적인 결론이다.** 점수를 채우기 위해 촉매를 만들어내지 않는다.

## 절대 금지

- 공시 근거(rcept_no) 없는 촉매 등재 — 이 모듈의 존재 이유를 무너뜨린다.
- 뉴스·기억·업계 상식 기반 촉매 생성.
- 공시에 없는 시점·금액 추정, 촉매 효과의 수치화(EPS·목표주가·상승 여력).
- CAT-04 를 정방향으로 채점.
- 데이터 부족을 0점으로 처리 (→ N/A + na_reason).
