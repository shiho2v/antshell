# business — 등급 정의 (rubric)

> 이 문서는 **Claude 가 읽는 산문**이다. 채점 산술은 `config/module-registry.yaml` 과
> `scripts/score_modules.py` 가 한다. 불일치 시 **registry 가 이긴다.**
> 등급은 모두 **0~3 서수**이며, 판단 불가는 **0 이 아니라 null(N/A)** 이다.

## 채점 항목 (5개 — 이것이 전부다)
| ID | 항목 | 가중치 | 근거 최소 | 비고 |
|----|------|--------|-----------|------|
| BUS-01 | 사업모델 명료성 | 20 | 1 | |
| BUS-02 | 매출구조 이해도 | 20 | 1 | |
| BUS-03 | 집중도 위험 (제품·고객·지역) | 20 | 1 | **inverse — 등급이 높을수록 집중도 위험이 낮다** |
| BUS-04 | 자본집약도와 고정비 구조 | 20 | 1 | |
| BUS-05 | 실적 변동성의 원천 규명 | 20 | 1 | |

## BUS-01 사업모델 명료성
"무엇을 만들어 누구에게 파는가"가 근거로 확정되는 정도.

- **3** — 사업부문 구분과 각 부문의 제품·서비스·전방 산업이 사업보고서 원문(`B-FILING-001`)에
  명시되어 있고, 수익 창출 경로(누구에게, 무엇을, 어떤 형태로 파는지)를 원문 문구로 재구성할 수 있다.
- **2** — 주력 제품·서비스와 전방 산업은 원문으로 확인되나, 부문 구분이 모호하거나 일부 부문의
  사업 내용이 서술되지 않았다.
- **1** — 기업개황(`B-PROFILE-001`)의 업종코드·법인 정보 수준만 있고, 제품·서비스는 원문 근거로
  특정되지 않는다. 사업의 윤곽만 안다.
- **0** — 확보된 근거가 사업의 정체를 설명하지 못한다 (근거는 있으나 내용이 공허한 경우).
- **N/A** — evidence pack 에 business 근거가 하나도 없을 때. (실무상 `B-PROFILE-001` 은 항상
  존재하므로 N/A 는 드물다.)

## BUS-02 매출구조 이해도
매출이 어디서 나오고 무엇에 반응하는지 아는 정도.

- **3** — 부문별/제품별 매출 비중이 원문에 **수치로** 제시되어 있고, 지역별 매출 구성도 확인되며,
  매출이 단가·물량·환율·전방수요 중 무엇에 반응하는지 원문 서술로 연결된다.
- **2** — 부문별 또는 제품별 매출 비중 중 **하나**가 원문에 있고, 나머지는 정성 서술로만 확인된다.
- **1** — 매출을 만드는 제품군은 알지만 비중이 수치로 확인되지 않는다. 구조를 정성적으로만 안다.
- **0** — 매출 구성에 대해 어떤 근거도 확인되지 않으면서 근거가 존재하는 경우.
- **N/A** — `B-FILING-001` 미확보. **사업부문별 매출은 구조화 DART API 가 없어 원문 외에는
  얻을 수 없다.** 이 경우 추정 금지, level=null,
  na_reason="사업보고서 원문 미확보(--with-document 미사용) — 부문별 매출 확인 불가".

## BUS-03 집중도 위험 (inverse)
**등급이 높을수록 위험이 낮다.** 편중이 확인될수록 등급을 낮춘다.

- **3** — 제품·고객·지역 세 축 모두 분산이 원문으로 확인된다 (특정 제품/고객/지역 편중 서술이 없고,
  비중이 제시된 경우 최대 축이 뚜렷하게 지배적이지 않다).
- **2** — 한 축에 상당한 편중이 있으나(예: 특정 제품군 또는 특정 지역 비중이 높음), 나머지 축은
  분산되어 있어 단일 충격이 전사 실적을 좌우하지는 않는다.
- **1** — 두 축 이상에서 편중이 확인된다 (예: 단일 제품군 + 특정 지역 집중).
- **0** — 원문이 특정 소수 고객/단일 제품에 대한 매출 의존을 **명시**한다 (예: "주요 매출처
  ○○사", 매출의 대부분이 단일 품목).
- **N/A** — 제품·고객·지역 편중을 확인할 원문 근거가 없다. **"모르니까 위험하다"로 0 을 주지 않는다.**
  na_reason 에 확인 불가 사유를 적는다. 고객사명은 **절대 추정하지 않는다.**

## BUS-04 자본집약도와 고정비 구조
설비 의존도와 가동률 레버리지를 이해한 정도.

- **3** — 생산능력·생산실적·가동률이 원문에 수치로 있고, `capex_to_ocf`·`net_debt_to_equity`
  지표와 결합해 고정비 레버리지(가동률 변동이 마진에 미치는 영향)를 근거로 설명할 수 있다.
- **2** — 설비 기반 사업임이 원문으로 확인되고 CAPEX 지표로 자본집약도를 뒷받침하나,
  가동률 수치가 없어 레버리지 크기를 특정하지 못한다.
- **1** — 자본집약도를 지표(`capex_to_ocf`)로만 유추할 수 있고, 고정비 구조에 대한 원문 서술이 없다.
- **0** — 자본 구조에 대한 근거가 있으나 사업의 비용 구조를 전혀 설명하지 못한다.
- **N/A** — 생산능력·가동률 원문도 없고 관련 지표도 N/A 인 경우.
  **생산능력·가동률은 구조화 API 가 없다.** 추정 금지.

## BUS-05 실적 변동성의 원천 규명
"이 회사 실적을 흔드는 것은 무엇인가"를 특정한 정도.

- **3** — 변동성의 원천(전방 사이클, 원재료 가격, 환율, 고객사 재고조정, 단일 대형 프로젝트 등)을
  **원문 근거로** 2개 이상 특정하고, 각각이 매출 또는 마진의 어느 지점을 때리는지 연결한다.
- **2** — 주된 변동 요인 1개를 원문 근거로 특정하고 전달 경로를 설명한다.
- **1** — 변동 요인을 지목하나 근거가 간접적이다(예: 원재료 목록만 있고 가격 민감도 서술 없음).
- **0** — "경기 변동에 영향을 받는다" 수준의 일반론뿐이다. **일반론은 0 이다.**
- **N/A** — 원문 미확보로 변동 요인을 특정할 근거가 전혀 없을 때.

## 공통 N/A 규칙 (반드시 준수)
- **N/A 는 0점이 아니다.** level=null 로 두면 Python 이 분자·분모 모두에서 제외한다.
- 데이터 부족은 점수가 아니라 **confidence / evidence_coverage 하락**으로 표현된다.
- **시장점유율·경쟁사·고객사명·컨센서스·목표주가는 UNSUPPORTED** — 생성 금지, `unknowns` 로 보낸다.
- 근거 1개 미만이면 level 을 제출해도 Python 이 N/A 처리한다 (requires_evidence=1).
