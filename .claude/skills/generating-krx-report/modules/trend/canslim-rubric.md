# trend — CANSLIM 채점 기준 (해석용 서술)

> **주의:** 점수는 `config/module-registry.yaml` 이 결정한다. 이 문서는 서술일 뿐 채점하지 않는다.
> 7항목 전부 `type: auto` — Python 이 metrics 값으로 채점한다. Claude 는 level 을 제출하지 않는다.
> 등급은 모두 **0~3**. **값이 없으면 N/A(채점 제외)이며 0점이 아니다.**
>
> CANSLIM 은 이 스킬의 최상위 프레임이 아니라 **trend 모듈의 하위 루브릭**이다.

## C — 최근 분기 실적 (TRD-C, 가중치 15, `eps_yoy_q`, %, higher_better)

**`reuse_from: growth` — growth 모듈 GRO-03 의 값과 evidence 를 재참조한다. 재계산 금지.**

| 등급 | 구간 |
|------|------|
| 0 | EPS YoY < 0% (감익) |
| 1 | 0 ~ 15% |
| 2 | 15 ~ 25% |
| 3 | ≥ 25% |

- 밴드 경계가 growth(GRO-03: 15/40)와 다르다. **값은 같고 밴드만 다르다** — 값을 다시 만들지 않는다.
- 인접 분기 보고서가 결측이면 N/A + 사유. 추정 금지.

## N — 신제품·신경영·신고가 (TRD-N, 가중치 15, `pct_from_52w_high`, %, higher_better)

52주 고점 대비 현재가 괴리율. **0에 가까울수록 신고가 근접 → 높은 등급.**

| 등급 | 구간 |
|------|------|
| 0 | < −25% (고점 대비 25% 넘게 하락) |
| 1 | −25 ~ −15% |
| 2 | −15 ~ −5% |
| 3 | ≥ −5% (신고가 근접) |

- 정성적 "신제품·신경영" 근거는 `data/raw/{ticker}_dart_events.json` 의 공시에서 인용한다
  (신규수주, 설비투자, 지배구조 변경 등). **보조 서술일 뿐이며 점수는 신고가 근접도가 결정한다.**
- 공시 없는 "신제품"은 쓰지 않는다. 뉴스·기억으로 만들지 않는다.

## 자격증명이 없을 때의 처리

- L·I·M 세 항목이 모두 **N/A** 가 된다 (never 0). 채점되는 항목은 C·A·N·S 넷뿐이다.
- 이때 CANSLIM 점수는 채점된 항목의 가중치만 재정규화해 산출되며(Python 담당),
  `evidence_coverage` 는 4/7 로 떨어진다. **이 사실을 verdict 와 unknowns 에 명시한다.**
- 시장 국면은 **미확인**이다. "현재 강세장이므로 M 은 양호" 같은 서술은 금지다.
