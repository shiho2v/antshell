## 1. 20개 장 구조

보고서는 아래 순서를 따른다. 실행하지 않은 모듈의 장은 **생략하지 말고 "미실행" 사유를 적는다.**

| # | 장 | 핵심 내용 |
|---|---|---|
| 1 | **분석 범위와 Analysis Contract** | 실행 모듈, 분석 모드, 데이터 기준일, unsupported 항목, 자격증명 유무 |
| 2 | **Executive Summary** | 아래 2절 규격을 그대로 따른다 |
| 3 | **기업 한 줄 정의** | "무엇을 팔아 어떻게 돈을 버는가" 한 문장 |
| 4 | **기업 개요** | 상장시장, 설립, 발행주식수 (전부 DART 근거) |
| 5 | **사업구조와 수익모델** | business 모듈. 사업부문별 **수치는 없다** — 원문 서술 인용만 |
| 6 | **기업 품질** | quality 모듈 (영업이익률·ROE·현금전환·FCF·레버리지·희석) |
| 7 | **성장성** | growth 모듈. 분기단독 YoY 와 3년 CAGR |
| 8 | **경쟁우위** | moat 모듈. 근거 2종 이상 없으면 등급 없이 "확인 불가" |
| 9 | **밸류에이션** | valuation 모듈. 자체계산 PER 과 KRX 공표 PER 충돌 시 병기 |
| 10 | **CANSLIM과 주가 추세** | trend 모듈. I·M·L 이 N/A 면 **N/A 라고 쓴다** |
| 11 | **주요 촉매** | catalyst 모듈. **공시에 없는 촉매는 등재 금지** |
| 12 | **핵심 위험** | risk 모듈 |
| 13 | **긍정·기준·부정 시나리오** | 전부 **조건부 문장**으로만. 확률·목표가 금지 |
| 14 | **투자 논리 훼손 조건** | 각 모듈의 `invalidating_conditions` 취합 |
| 15 | **향후 모니터링 지표** | 무엇을 언제 다시 확인할지 (다음 분기보고서 등) |
| 16 | **종합 평가** | 종합점수·등급·재정규화 여부 |
| 17 | **데이터 한계** | manifest 의 `data_limitations` + `unsupported_items` 전부 |
| 18 | **출처와 기준일** | manifest 의 `sources` 표 (provider/source_type/rcept_no/retrieved_at) |
| 19 | **검증 결과** | 4개 게이트 통과 여부와 경고 |
| 20 | **면책 문구** | 필수 |

## 2. Executive Summary 필수 항목

아래 9개를 **빠짐없이** 표시한다.

1. **분석 모드** (balanced / growth / value / long-term / momentum)
2. **종합점수** (0~100 또는 N/A)
3. **판단 신뢰도** (confidence, 0~1)
4. **데이터 완전성** (data_completeness, 0~1)
5. **가장 강한 모듈** (strongest_module)
6. **가장 약한 모듈** (weakest_module)
7. **핵심 투자포인트 3개** (각각 evidence ID 부착)
8. **핵심 위험 3개** (각각 evidence ID 부착)
9. **판단을 바꿀 조건** (무엇이 관찰되면 이 결론이 뒤집히는가)

일부 모듈만 실행해 가중치를 재정규화했다면 **그 사실을 여기에 명시**한다.

## 3. 문장 규칙

### 사실·해석·전망을 문장에서 구분 표기한다
- **사실**: 그대로 서술한다.
- **해석**: "…로 해석된다", "…로 보인다" 등 해석임을 드러낸다.
- **전망**: 반드시 조건부. "…하면 …할 수 있다".

### 모든 숫자에 (출처, 기준일)
- DART: `(출처: DART 연결재무제표, 기준일: 2026-03-31, [rcept_no 20250514000123](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20250514000123))`
- pykrx: `(출처: pykrx(비공식 래퍼, 원천 Naver Finance), 기준일: 2026-07-10)`
- 파생값: `(출처: 자체 계산 — 시가총액 ÷ TTM 순이익, 입력 근거 SH-MKTCAP-001·Q-NETINCOME-001)`
- **출처·기준일을 붙일 수 없는 숫자는 보고서에 넣지 않는다.**

### N/A 는 N/A 로 쓴다
빈칸도, 0 도, "-" 도 아니다. **반드시 사유를 붙인다.**
- 좋음: `CANSLIM I(수급): N/A — KRX 자격증명(KRX_ID/KRX_PW) 부재로 투자자별 순매수를 조회할 수 없다. 0점으로 채점하지 않았다.`
- 나쁨: `CANSLIM I: 0점` / `CANSLIM I: -` / (아예 생략)

### 분량 제한
- 모듈 서술(`verdict`) **500단어 이내**
- strengths / weaknesses **각 5개 이내**
- Executive Summary 는 한 화면에 들어오게

### 금지 표현
- **매수 / 매도 / 목표주가 / 적정주가 / 컨센서스 / buy / sell / overweight / underweight**
- 등급은 4개뿐: **긍정적 관찰 / 중립적 관찰 / 보수적 관찰 / 판단 유보**
- ("기관 순매수", "외국인 순매도" 같은 **수급 용어는 허용**된다 — 투자 권유가 아니다)

## 4. 좋은 문장 / 나쁜 문장

**밸류에이션**
- (O) "Trailing PER 은 12.4배다 (출처: 자체 계산 — DART 연결 TTM 순이익 기준, 기준일 2026-07-10, rcept_no 20250514000123). KRX 공표 PER 은 14.1배로 다르며 (출처: pykrx, 기준일 2026-07-10), 공표치는 최근 확정 재무제표를 사용해 최신 분기가 반영되지 않는다."
- (X) "PER 12.4배로 저평가 상태이며 목표주가 상향 여지가 있다." → 목표주가 금지, 저평가 단정 금지

**성장성**
- (O) "2026년 1분기 매출은 전년 동기 대비 18.4% 증가했다 (출처: DART, 분기 단독값 — 누적 보고서 차분으로 산출, rcept_no 20260514000456)."
- (X) "매출이 크게 늘어 성장세가 뚜렷하다." → 숫자·출처·기간 없음

**경쟁우위**
- (O) "사업보고서 원문은 고객사 인증 절차가 장기간 소요된다고 서술한다 (출처: DART 사업보고서 「II. 사업의 내용」, rcept_no 20260318000123). 영업이익률은 8개 분기 연속 두 자릿수를 유지했다 (출처: 자체 계산). 두 근거를 함께 볼 때 전환비용 기반의 진입장벽이 **있는 것으로 해석된다**."
- (X) "글로벌 시장점유율 1위의 강력한 해자를 보유하고 있다." → 시장점유율은 공시에 없다. 외부 지식 금지

**촉매**
- (O) "2026-06-20 신규 설비투자 결정 공시가 있었다 (출처: DART 주요사항보고서, rcept_no 20260620000789). 이 투자가 계획대로 가동되면 생산능력 확대로 이어질 수 있으나, 가동률·매출 기여는 공시되지 않아 확인할 수 없다."
- (X) "하반기 신규 수주가 본격화되며 실적이 개선될 전망이다." → 수주잔고는 구조화 데이터가 없다. 단정적 전망 금지

**데이터 부족**
- (O) "사업부문별 매출 구성은 **확인 필요** — DART 에 사업부문별 매출 엔드포인트가 존재하지 않으며, 사업보고서 서술에서 수치를 임의 추출하지 않는다."
- (X) "사업부문별 매출은 대략 A 60%, B 40% 수준으로 추정된다." → 추정 금지

**인과**
- (O) "영업이익률 개선과 매출 증가가 동시에 나타났다. 다만 이 둘의 인과관계는 공시 근거로 확인되지 않으며, 상관을 인과로 단정하지 않는다."
- (X) "판가 인상 덕분에 영업이익률이 개선되었다." → 판가 데이터 없음, causal_path 없음

## 5. 면책 문구 (필수)

> 본 보고서는 공개된 공시·시세 데이터를 기계적으로 집계·채점한 **교육용 예제**이며, **투자 자문이 아닙니다.**
> 특정 종목의 매매를 권유하지 않으며, 목표주가·투자의견을 제시하지 않습니다.
> 데이터는 기준일 시점의 것이며 이후 변경될 수 있습니다. 투자 판단과 그 결과의 책임은 투자자 본인에게 있습니다.

("투자 자문" 또는 "투자자문" 문자열이 없으면 Gate 4 가 실패한다.)
