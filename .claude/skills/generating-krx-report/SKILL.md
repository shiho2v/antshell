# Generating KRX Report Skill

한국 주식 종목을 **실제 데이터 기반으로** 분석해 CANSLIM 채점 HTML 보고서를 만든다.
스터디 예제 스킬이며, 종목 미지정 시 기본 예시는 **삼성전기(009150)**.

> ⚠️ 이 스킬은 데이터 정직성이 최우선이다. 작업 전 반드시
> `references/data-honesty.md`를 읽고 3대 원칙을 지킨다. **수치를 직접 추정하지 않는다.**

## 워크플로 (5단계)

### 1. 종목코드 확인
- 사용자가 6자리 티커를 주면 그대로 사용.
- 종목명만 주면(예: "삼성전기") **추측하지 말고** 사용자에게 6자리 코드를 확인 요청한다.
  - 참고용으로 후보 코드를 제시할 수는 있으나, 확정은 사용자 확인 후.
- 아무 종목도 없으면 기본 예시 `009150`(삼성전기)로 진행하되 예시임을 명시.

### 2. 데이터 수집 (두 스크립트 실행 — 직접 추정 금지)
스킬 디렉터리에서 두 스크립트를 Bash로 실행한다. `{CODE}`는 6자리 코드.

```bash
# 재무 데이터 (환경변수 DART_API_KEY 필요)
python .claude/skills/generating-krx-report/scripts/fetch_dart.py {CODE}
# 시세·수급 데이터 (수급 I 항목은 환경변수 KRX_ID/KRX_PW 필요)
python .claude/skills/generating-krx-report/scripts/fetch_price.py {CODE}
```

- 키는 프로젝트 `.env`에 두고 실행 전 셸에 export 한다(예: `export DART_API_KEY=...`).
  `DART_API_KEY` 없으면 C·A가, `KRX_ID`/`KRX_PW` 없으면 I가 각각 N/A로 남는다(추정 금지).

- 산출물: `data/{CODE}_fundamentals.json`, `data/{CODE}_market.json`
- 스크립트가 에러로 종료하면(키 없음/조회 실패 등) **보고서를 만들지 말고**
  에러 메시지를 사용자에게 그대로 전달하고 멈춘다. 임의 수치로 채우지 않는다.

### 3. CANSLIM 채점 (JSON 수치로만)
- `references/canslim-rubric.md`를 읽어 채점 기준을 로드한다.
- **오직 두 JSON 파일의 수치로만** C / A / S / L / I 를 채점한다.
- 데이터가 없거나 계산 불가한 항목(전년 동기 없음, EPS 결측 등)은 점수 대신 **N/A**로 둔다.
  - `N/M`(Not Meaningful), 결측치는 N/A 처리하고 사유를 1줄 기록.
- **M(시장 방향)은 지수 데이터를 수집하지 않으므로 N/A 고정** (v2 확장 예정).
- 각 항목 근거는 반드시 JSON의 수치 + (출처, 기준일)로 뒷받침한다.

### 4. HTML 보고서 생성
- `templates/report.html`을 읽어 자리표시자(`{{...}}`)를 채운다.
- 저장 위치: `outputs/{CODE}_report_{조회일}.html` (조회일은 market.json의 `as_of`).
- 모든 수치 옆에 `<출처, 기준일>` 태그를 표기한다.

### 5. 자체 검증 체크리스트
보고서 저장 후 아래를 스스로 점검하고 통과 여부를 사용자에게 보고한다.
- [ ] 모든 수치에 (출처, 기준일) 태그가 붙어 있는가?
- [ ] N/A 항목에 점수를 부여하지 않았는가? (M은 반드시 N/A)
- [ ] JSON에 없는 외부 지식으로 수치를 보완하지 않았는가?
- [ ] "본 보고서는 투자 자문이 아니며 교육용 예제"라는 고지가 포함됐는가?
- [ ] 총점은 채점된(N/A 아님) 항목만으로 계산했는가?

## 참고 문서
- `references/data-honesty.md` — 환각 방지 3대 원칙 (작업 전 필독)
- `references/canslim-rubric.md` — C/A/N/S/L/I/M 채점 세부 기준

## 총점 산정 규칙
- 채점 가능한 항목의 점수 합 / (채점 항목 수 × 10) × 100 = 백분율.
- N/A 항목은 분모·분자 모두에서 제외한다. (점수를 0으로 치지 않는다.)
- 보고서에 "채점 항목 n개 기준"을 명시한다.

## 주의

- 데이터 조회 실패 시 조용히 넘어가지 말고 반드시 사용자에게 알린다.
