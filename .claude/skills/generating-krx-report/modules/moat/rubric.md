# moat — 등급 정의 (rubric)

> 이 문서는 **Claude 가 읽는 산문**이다. 채점 산술은 `config/module-registry.yaml` 과
> `scripts/score_modules.py` 가 한다. 불일치 시 **registry 가 이긴다.**
>
> **이 모듈의 제1원칙: 근거가 없으면 해자는 "없는 것"이 아니라 "확인되지 않은 것"(N/A)이다.**
> level 0 은 "근거가 해자의 부재를 보여준다"는 적극적 판단이다. "모르겠다"는 **반드시 null** 이다.

## 채점 항목 (5개 — 이것이 전부다)
| ID | 항목 | 가중치 | 근거 최소 | 근거 종류 |
|----|------|--------|-----------|-----------|
| MOA-01 | 기술·품질·인증 장벽 | 20 | **2** | **서로 다른 종류(distinct) 필수** |
| MOA-02 | 원가우위와 규모의 경제 | 20 | **2** | **distinct 필수** |
| MOA-03 | 고객 전환비용과 공급망 지위 | 20 | **2** | **distinct 필수** |
| MOA-04 | 연구개발·특허 축적 | 15 | 1 | — |
| MOA-05 | 수익성 지속성 (해자의 재무적 발현) | **25** | **2** | hint: `operating_margin_ttm`, `roe_ttm` |

`distinct_evidence_types` = evidence item 의 `evidence_type`
(`filing_text` / `metric` / `statement` / `event`)이 서로 달라야 한다.
같은 근거를 두 번 세는 것으로는 요건을 채우지 못한다 → 못 채우면 **N/A**.

## MOA-01 기술·품질·인증 장벽
- **3** — 사업보고서 원문이 진입장벽을 **구체적으로** 서술한다(고객 승인·규격 인증 절차, 공정 난이도,
  수율·신뢰성 요구). 그 장벽이 높은 마진(`operating_margin_ttm`)으로 발현되는 것까지 연결된다.
  서로 다른 종류의 근거 2개 이상.
- **2** — 인증·품질 요구가 원문에 언급되고 재무 발현이 부분적으로 확인되나, 장벽의 **높이**를
  특정할 서술이 부족하다.
- **1** — 기술적 성격의 사업임은 확인되나(제품 서술 수준), 장벽으로 볼 만한 구체적 서술이 없다.
- **0** — 근거는 확보했으나, 원문이 범용 제품·표준품 위주임을 보여준다(= 장벽 부재의 적극적 증거).
- **N/A** — `B-FILING-001` 미확보, **또는** 서로 다른 종류의 근거를 2개 모으지 못함.
  → `level: null`, na_reason 명시. **추정 금지.**

## MOA-02 원가우위와 규모의 경제
- **3** — 원문이 규모(생산능력)·수직계열화·내재화·원재료 조달 구조를 서술하고, 그것이 동종 대비
  원가 우위로 이어진다는 근거가 있다 + 재무 지표로 뒷받침된다. distinct 근거 2개 이상.
- **2** — 규모 또는 내재화 중 하나가 원문으로 확인되나, 원가 우위로의 연결이 정성 수준에 머문다.
- **1** — 생산 규모는 확인되나 원가 구조에 대한 서술이 없다.
- **0** — 근거가 원가 열위 또는 원재료 가격에 대한 높은 노출을 보여준다.
- **N/A** — 생산능력·원가 구조 서술 부재(구조화 API 없음) 또는 distinct 근거 2개 미확보.
  **경쟁사 대비 원가 비교는 UNSUPPORTED — 절대 생성하지 않는다.**

## MOA-03 고객 전환비용과 공급망 지위
- **3** — 원문이 design-in(고객 설계 단계 참여), 장기공급계약, 인증된 부품의 교체 난이도,
  소수 공급사 체제 중 하나 이상을 **명시**하고, 그 결과 고객이 쉽게 이탈하지 못함을 보여준다.
  distinct 근거 2개 이상.
- **2** — 공급망 내 위치나 계약 형태가 원문으로 확인되나, 전환비용의 크기를 특정하지 못한다.
- **1** — 고객 구조에 대한 서술은 있으나 전환비용을 시사하지 않는다.
- **0** — 근거가 범용·스팟 거래 중심 구조를 보여준다(= 전환비용 부재의 적극적 증거).
- **N/A** — 고객·계약 관련 원문 근거 부재 또는 distinct 근거 2개 미확보.
  **고객사명은 원문에 명시된 경우에만 인용한다. 추정 금지.**

## MOA-04 연구개발·특허 축적
- **3** — 원문이 특허 보유·연구개발 조직·기술 성과를 구체적으로 서술하고, 이것이 제품 경쟁력과
  연결된다.
- **2** — R&D 활동과 기술 축적이 원문에 서술되나 성과의 구체성이 낮다.
- **1** — R&D 조직의 존재만 확인된다.
- **0** — 근거가 R&D 투자·기술 축적이 사실상 없음을 보여준다.
- **N/A** — 원문 미확보. **R&D 지출 금액은 구조화 DART API 가 없다** — 원문에만 있다.
  원문이 없으면 이 항목은 N/A 이며 0 이 아니다.

## MOA-05 수익성 지속성 — 해자의 재무적 발현 (가중치 25, 최대)
해자가 실재한다면 **높은 마진과 자본수익률로 나타나야 한다.** 이 항목은 그 발현을 본다.
- **3** — `operating_margin_ttm` 과 `roe_ttm` 이 모두 높은 수준이고(각각 QUA-01·QUA-02 의 최상위
  밴드), **MOA-01~04 중 하나 이상의 정성 근거와 인과적으로 연결**되어 설명된다.
- **2** — 마진 또는 ROE 중 하나가 견조하며, 정성 근거와의 연결이 부분적으로 성립한다.
- **1** — 재무 지표는 확보됐으나 수준이 평범하고, 해자와의 인과 연결이 서술되지 않는다.
- **0** — 마진·ROE 가 낮다 — 해자가 있더라도 재무로 발현되고 있지 않다.
- **N/A** — `operating_margin_ttm`·`roe_ttm` 이 모두 N/A 이거나, 근거 2개를 확보하지 못한 경우.

### MOA-05 의 한계 (rationale 에 반드시 적을 것)
- **연도별 마진 추이(`operating_margin_history`)는 현재 계산되지 않는다.**
  따라서 "지속성"을 **시계열로 입증할 수 없다.** 단일 시점 TTM 마진만으로 지속성을 단정하지 말고,
  등급을 보수적으로 잡는다.
- 높은 마진은 사이클 호황의 결과일 수도 있다. 이 가능성을 `counter_evidence` 에 남긴다.
- **경쟁사 대비 마진 비교는 데이터가 없다(UNSUPPORTED).** 절대 생성하지 않는다.

## 공통 N/A 규칙 (반드시 준수)
- **N/A 는 0점이 아니다.** level=null 이면 Python 이 분자·분모에서 제외한다.
- **시장점유율·경쟁사 자동선정·경쟁사 마진·컨센서스·목표주가는 UNSUPPORTED** — 생성 금지.
  필요하면 `unknowns` 로 보낸다.
- 브랜드·네트워크 효과는 대부분의 제조업 사업보고서에 근거가 없다. **없으면 N/A 로 두고,
  "브랜드 파워가 있다" 같은 문장을 쓰지 않는다.**
- 데이터 부족은 점수가 아니라 **confidence / evidence_coverage 하락**으로 표현된다.
- 근거 요건(개수·distinct) 미충족 시 level 을 제출해도 Python 이 자동 N/A 처리한다.
