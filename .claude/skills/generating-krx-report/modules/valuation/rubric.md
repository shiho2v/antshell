# valuation — 채점 기준 (해석용 서술)

> **주의:** 점수는 `config/module-registry.yaml` 이 결정한다. 이 문서는 그 기준을 사람과 Claude가
> 읽기 위한 서술일 뿐이며 **채점에 사용되지 않는다.** 불일치 시 registry 가 이긴다.
> 6개 항목 전부 `type: auto` — Python 이 metrics 값과 밴드로 채점하고, Claude 는 해석만 쓴다.
> 등급은 모두 **0~3**. **값이 없으면 N/A(채점 제외)이며 0점이 아니다.**

## VAL-01 · Trailing PER (가중치 22, `per_trailing`, 단위 x, lower_better)

| 등급 | 구간 | 해석 |
|------|------|------|
| 3 | PER < 8 | 이익 대비 가격이 낮다. 이익의 지속성·일회성 여부를 반드시 함께 확인한다. |
| 2 | 8 ≤ PER < 15 | 평균적 수준. |
| 1 | 15 ≤ PER < 25 | 이익 성장이 전제되어야 정당화되는 구간. |
| 0 | PER ≥ 25 | 가격에 상당한 성장 기대가 내재. |

- **적자기업은 N/A** (`na_if_negative_earnings: true`). **0점을 주지 않는다.**
- TTM 순이익 기반 자체 계산값을 본문에 쓴다. KRX 공표 PER 과 다르면 counter_evidence 에 병기한다.

## VAL-02 · PBR (가중치 18, `pbr`, 단위 x, lower_better)

| 등급 | 구간 |
|------|------|
| 3 | PBR < 0.8 |
| 2 | 0.8 ≤ PBR < 1.5 |
| 1 | 1.5 ≤ PBR < 3.0 |
| 0 | PBR ≥ 3.0 |

- **반드시 ROE(`roe_ttm`)와 함께 해석한다.** PBR 은 단독으로 의미가 없다.
  - 낮은 PBR + 낮은 ROE = 저평가가 아니라 **자본 수익성의 문제**일 수 있다.
  - 높은 PBR + 높은 ROE = 시장이 자본 수익성에 프리미엄을 지불하고 있는 상태다.
- 자산 재평가·무형자산 비중이 큰 기업은 장부가 자체의 신뢰도를 unknowns 에 적는다.

## VAL-03 · EV/EBITDA (가중치 20, `ev_ebitda`, 단위 x, lower_better)

| 등급 | 구간 |
|------|------|
| 3 | < 5 |
| 2 | 5 ~ 9 |
| 1 | 9 ~ 14 |
| 0 | ≥ 14 |

- **EBITDA ≤ 0 이면 N/A** (0점 아님).
- 자본구조 중립 지표다. `net_debt` 을 함께 인용해 부채 부담을 설명한다.
- EBITDA 는 감가상각을 제외하므로 **설비투자 부담이 큰 기업의 실질 현금창출력을 과대평가**한다.
  자본집약 기업이라면 FCF Yield(VAL-05)와 반드시 교차 확인한다.

## VAL-04 · Earnings Yield (가중치 15, `earnings_yield`, 단위 %, higher_better)

| 등급 | 구간 |
|------|------|
| 0 | < 3% |
| 1 | 3 ~ 6% |
| 2 | 6 ~ 10% |
| 3 | ≥ 10% |

- PER 의 역수 성격. 현재 이익 수준이 유지된다는 가정 하의 수익률이며 **미래 수익률 약속이 아니다.**
- 사이클 고점 이익이라면 이 수치는 과대평가된다 — 사이클 위치를 함께 서술한다.

## VAL-05 · FCF Yield (가중치 15, `fcf_yield`, 단위 %, higher_better)

| 등급 | 구간 |
|------|------|
| 0 | < 0% |
| 1 | 0 ~ 3% |
| 2 | 3 ~ 6% |
| 3 | ≥ 6% |

- 회계이익이 아닌 **실제 현금** 기준. Earnings Yield 와의 괴리가 크면 그 원인
  (운전자본 증가, 대규모 capex, 일회성 항목)을 지목하고, 못 밝히면 unknowns 에 남긴다.
- 증설 사이클 진입 기업은 FCF 가 일시적으로 음수일 수 있다 — 사실만 적고 미래를 추정하지 않는다.

## VAL-06 · PSR (가중치 10, `psr`, 단위 x, lower_better)

| 등급 | 구간 |
|------|------|
| 3 | < 0.5 |
| 2 | 0.5 ~ 1.5 |
| 1 | 1.5 ~ 3.0 |
| 0 | ≥ 3.0 |

- **반드시 영업이익률(`operating_margin_ttm`)과 함께 해석한다.**
  이익률이 낮은 기업의 낮은 PSR 은 저평가 신호가 아니다. 매출은 이익이 아니다.
- 적자·저마진 기업에서 PER/EV/EBITDA 가 N/A 일 때 보조 지표로서의 가치가 있다.

## 교차 해석 체크리스트

- PBR ↔ ROE, PSR ↔ 영업이익률, Earnings Yield ↔ FCF Yield, EV/EBITDA ↔ net_debt.
- 멀티플 ↔ 성장률(`rev_cagr_3y`, `op_cagr_3y`) — **정성 서술만. PEG 계산 금지.**
- 역사적 밴드: KRX_ID/KRX_PW 있을 때만. 없으면 **N/A**.
- 동종기업 비교: analysis_contract 에 비교기업이 명시된 경우에만.

## 절대 금지

- Forward PER, Forward EPS, 컨센서스, **목표주가**, 시장점유율 → 데이터 자체가 없다. 생성 금지.
- N/A 항목에 0점 부여 금지.
- 시가총액은 종가(다른 기준일) × 발행주식수(사업보고서 기준일)이다 — 한계를 반드시 밝힌다.
