# quality — 밴드 정의 (rubric)

> 이 모듈의 6개 criterion 은 전부 **`auto`** 다.
> `score_modules.py` 가 `metrics.json` 값을 registry 의 bands 에 넣어 **자동으로** level 을 정한다.
> **Claude 는 level 을 제출하지 않는다.** 아래 표는 Claude 가 **수치를 해석**할 때 쓰는 지도다.
> 산술의 단일 진실 원천은 `config/module-registry.yaml` 이며, 불일치 시 registry 가 이긴다.

## 채점 항목 (6개 — 이것이 전부다)
| ID | 항목 | 가중치 | metric | 방향 | 단위 |
|----|------|--------|--------|------|------|
| QUA-01 | 영업이익률 (TTM) | 18 | `operating_margin_ttm` | higher_better | % |
| QUA-02 | ROE (TTM) | 18 | `roe_ttm` | higher_better | % |
| QUA-03 | 현금전환율 (영업현금흐름/당기순이익) | 18 | `cash_conversion_ttm` | higher_better | x |
| QUA-04 | 잉여현금흐름 마진 | 16 | `fcf_margin_ttm` | higher_better | % |
| QUA-05 | 순차입금/자기자본 | 15 | `net_debt_to_equity` | **lower_better** | x |
| QUA-06 | 주식 희석 (1년 발행주식수 증가율) | 15 | `share_change_1y` | **lower_better** | % |

## QUA-01 영업이익률 TTM — `operating_margin_ttm` (%)
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 15 | 본업에서 확고한 가격결정력 또는 원가우위가 재무로 발현된다 |
| 2 | 8 ~ 15 | 건전한 본업 수익성. 사이클 하강기 방어력은 별도 확인 필요 |
| 1 | 3 ~ 8 | 얇은 마진. 고정비 레버리지에 따라 적자 전환 여지가 있다 |
| 0 | < 3 | 마진이 거의 없다 (적자 포함) |
- **N/A** — 매출 또는 영업이익 TTM 결측. `ttm_fallback: true` 면 연간값 폴백이므로 verdict 에 명시한다.

## QUA-02 ROE TTM — `roe_ttm` (%)
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 15 | 자기자본 대비 높은 이익. 단, 레버리지 기여를 `net_debt_to_equity`로 반드시 교차 확인 |
| 2 | 10 ~ 15 | 자본비용을 넘어설 가능성이 있는 수준 |
| 1 | 5 ~ 10 | 낮다. 자본 효율이 개선되는 추세인지 별도 확인 필요 |
| 0 | < 5 | 자본을 이익으로 바꾸지 못하고 있다 (적자 포함) |
- **한계** — 분모가 **평균자본이 아닌 기말자본**이다. 인용 시 함께 적는다.
- **N/A** — 순이익 TTM 또는 자본총계 결측.

## QUA-03 현금전환율 — `cash_conversion_ttm` (배)
= 영업현금흐름 TTM / 당기순이익 TTM
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 1.1 | 회계이익보다 현금이 더 들어온다. 이익의 질이 높다 |
| 2 | 0.8 ~ 1.1 | 이익이 대체로 현금으로 회수된다 |
| 1 | 0.5 ~ 0.8 | 이익의 상당 부분이 운전자본에 묶여 있을 가능성 |
| 0 | < 0.5 | 회계이익과 현금의 괴리가 크다. 이익의 질을 의심해야 한다 |
- **N/A (중요)** — **순이익이 0 이하이면 이 지표는 정의되지 않는다.** N/A 이며, 이를
  "현금창출력 0" 으로 서술하면 안 된다.

## QUA-04 잉여현금흐름 마진 — `fcf_margin_ttm` (%)
= (영업현금흐름 − |CAPEX|) / 매출 × 100
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 8 | 재투자 후에도 매출의 8% 이상이 현금으로 남는다 |
| 2 | 3 ~ 8 | 재투자를 감당하고 현금이 남는다 |
| 1 | 0 ~ 3 | 잉여현금이 간신히 양수다 |
| 0 | < 0 | 재투자가 영업현금을 초과한다. 성장 투자인지 현금 소진인지 `capex_to_ocf`로 구분 서술 |
- **N/A** — OCF 또는 CAPEX 결측.

## QUA-05 순차입금/자기자본 — `net_debt_to_equity` (배) · **lower_better**
| level | 구간 | 해석 |
|-------|------|------|
| 3 | < 0 | **순현금** — 차입금보다 현금이 많다 |
| 2 | 0 ~ 0.5 | 보수적 레버리지 |
| 1 | 0.5 ~ 1.0 | 레버리지가 실적 변동성을 증폭할 수 있다 |
| 0 | ≥ 1.0 | 자기자본을 넘는 순차입금. `interest_coverage`로 상환 능력을 반드시 함께 본다 |
- **N/A (중요)** — 차입금 또는 현금 계정을 확정하지 못한 경우. **"무차입"이 아니라 "미확인"이다.**
  절대 순현금으로 해석하지 않는다.

## QUA-06 주식 희석 — `share_change_1y` (%) · **lower_better**
= (최근 발행주식수 − 직전 발행주식수) / 직전 × 100
| level | 구간 | 해석 |
|-------|------|------|
| 3 | < 0.5 | 사실상 희석 없음 (감소 포함 — 자사주 소각 가능성) |
| 2 | 0.5 ~ 2 | 경미한 희석 |
| 1 | 2 ~ 5 | 기존 주주 지분이 눈에 띄게 희석됐다 |
| 0 | ≥ 5 | 대규모 희석. 조달 목적과 사용처를 공시로 확인해야 한다 |
- **한계** — 사업보고서 **연 1회 스냅샷** 기준. 기중 증자 반영이 지연될 수 있다.
- **N/A** — 발행주식수 스냅샷이 1개뿐이라 증감률을 낼 수 없는 경우.

`roic_ttm` (**유효세율·투하자본 가정 명시 필수**),

`current_ratio`, `capex_to_ocf`, `fcf_ttm`, `ebitda_ttm`.

## 공통 N/A 규칙
- **N/A 는 0점이 아니다.** 값이 null 이면 Python 이 분자·분모에서 제외한다.
- 데이터 부족은 점수가 아니라 **confidence / evidence_coverage 하락**으로 나타난다.
- 산업 평균·경쟁사 대비 비교는 **UNSUPPORTED** — 하지 않는다.
- Claude 는 이 모듈에서 **level 을 제출하지 않는다.** verdict·strengths·weaknesses 만 쓴다.
