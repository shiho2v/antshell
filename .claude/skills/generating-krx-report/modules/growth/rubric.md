# growth — 밴드 정의 (rubric)

> 이 모듈의 7개 criterion 은 전부 **`auto`** 다. `score_modules.py` 가 `metrics.json` 값을
> registry bands 에 넣어 자동 채점한다. **Claude 는 level 을 제출하지 않는다.**
> 아래 표는 Claude 가 수치를 **해석**할 때 쓰는 지도다. 산술의 단일 진실 원천은
> `config/module-registry.yaml` 이며, 불일치 시 registry 가 이긴다.

## 채점 항목 (7개 — 이것이 전부다)
| ID | 항목 | 가중치 | metric | 단위 |
|----|------|--------|--------|------|
| GRO-01 | 최근 분기 매출 YoY (분기 단독) | 18 | `rev_yoy_q` | % |
| GRO-02 | 최근 분기 영업이익 YoY (분기 단독) | 20 | `op_yoy_q` | % |
| GRO-03 | 최근 분기 EPS YoY | 18 | `eps_yoy_q` | % |
| GRO-04 | 3년 매출 CAGR | 15 | `rev_cagr_3y` | % |
| GRO-05 | 3년 영업이익 CAGR | 15 | `op_cagr_3y` | % |
| GRO-06 | 성장 가속도 | 7 | `growth_acceleration_pp` | %p |
| GRO-07 | 수익성 동반 성장 | 7 | `profitable_growth_gap_pp` | %p |

**GRO-03 과 GRO-05 는 trend 모듈의 CANSLIM C·A 로 재사용된다. trend 에서 재계산 금지.**

---

## GRO-01 최근 분기 매출 YoY — `rev_yoy_q` (%)
전년 **동일 분기** 단독값 대비 증감률. 누적(YTD) 아님.
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 25 | 강한 톱라인 확장 |
| 2 | 10 ~ 25 | 뚜렷한 성장 |
| 1 | 0 ~ 10 | 완만한 성장 — 물가 상승분과 구분되지 않을 수 있다 |
| 0 | < 0 | 역성장 |
- **N/A** — 전년 동기 데이터 없음, 해당 분기 매출 결측, 또는 전년 동기 기준값이 0 이하.

## GRO-02 최근 분기 영업이익 YoY — `op_yoy_q` (%)
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 40 | 이익이 폭발적으로 증가 — 영업 레버리지 또는 기저효과를 구분해 서술 |
| 2 | 15 ~ 40 | 견조한 이익 성장 |
| 1 | 0 ~ 15 | 이익은 늘었으나 폭이 작다 |
| 0 | < 0 | 이익 감소 |
- **N/A** — 전년 동기 영업이익이 0 이하(적자)면 증감률이 의미를 갖지 않는다. **"성장 0%"가 아니다.**

## GRO-03 최근 분기 EPS YoY — `eps_yoy_q` (%) · **CANSLIM "C" 로 재사용**
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 40 | 주당이익 급증 |
| 2 | 15 ~ 40 | 견조한 주당이익 성장 |
| 1 | 0 ~ 15 | 소폭 증가 |
| 0 | < 0 | 주당이익 감소 |
- **주의** — EPS YoY 가 `op_yoy_q` 를 크게 웃돌면 영업외 이익·세금효과·자사주 소각 가능성이 있다.
  단정하지 말고 `counter_evidence` 로 남긴다.
- **N/A** — 전년 동기 EPS 결측 또는 0 이하.
- ※ trend 모듈의 TRD-C 는 **같은 metric** 을 쓰되 **밴드가 다르다**(0/15/25). 등급이 달라도
  모순이 아니다. 값은 하나이며 재계산하지 않는다.

## GRO-04 3년 매출 CAGR — `rev_cagr_3y` (%)
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 12 | 3년간 구조적 확장 |
| 2 | 5 ~ 12 | 꾸준한 성장 |
| 1 | 0 ~ 5 | 정체에 가깝다 |
| 0 | < 0 | 3년간 매출 축소 |
- **N/A** — 연말값이 4개 미만이거나, 기준연도 값이 0 이하여서 CAGR 이 정의되지 않는 경우.

## GRO-05 3년 영업이익 CAGR — `op_cagr_3y` (%) · **CANSLIM "A" 로 재사용**
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 18 | 이익의 구조적 성장 |
| 2 | 8 ~ 18 | 이익이 꾸준히 늘었다 |
| 1 | 0 ~ 8 | 이익 성장이 미약하다 |
| 0 | < 0 | 3년간 이익 감소 |
- **N/A** — 기준연도 영업이익이 0 이하(적자)면 CAGR 이 정의되지 않는다. **0점이 아니다.**
- ※ trend 의 TRD-A 는 **같은 metric**, 다른 밴드(0/10/20). 재계산 금지.

## GRO-06 성장 가속도 — `growth_acceleration_pp` (%p)
= 이번 분기 매출 YoY − 직전 분기 매출 YoY
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 5 | 성장률이 뚜렷하게 가속 |
| 2 | 0 ~ 5 | 완만한 가속 |
| 1 | -5 ~ 0 | 완만한 둔화 |
| 0 | < -5 | 뚜렷한 둔화 |
- **한계** — **연속 2개 분기만의 차분**이다. 장기 추세로 일반화하지 않는다.
- **N/A** — 두 분기 중 하나라도 YoY 를 산출할 수 없는 경우.

## GRO-07 수익성 동반 성장 — `profitable_growth_gap_pp` (%p)
= 영업이익 YoY − 매출 YoY
| level | 구간 | 해석 |
|-------|------|------|
| 3 | ≥ 10 | 매출보다 이익이 훨씬 빨리 늘었다 — 영업 레버리지가 강하게 작동 |
| 2 | 0 ~ 10 | 마진을 지키며 성장 |
| 1 | -5 ~ 0 | 성장의 대가로 마진이 소폭 훼손 |
| 0 | < -5 | 매출은 늘었으나 이익이 따라오지 못한다 — 성장의 질이 낮다 |
- **N/A** — 매출 또는 영업이익 YoY 중 하나라도 N/A 인 경우.

## 공통 N/A 규칙
- **N/A 는 0점이 아니다.** 값이 null 이면 Python 이 분자·분모에서 제외한다.
- **사업부별 성장률, 수주잔고, R&D 지출 증가율은 구조화 API 가 없다** →
  `--with-document` 로 확보한 사업보고서 원문이 있을 때만 **정성 인용**, 없으면 N/A.
  원문이 있어도 **성장률을 직접 계산하지 않는다.**
- **컨센서스·가이던스·경쟁사 성장률·목표주가는 UNSUPPORTED** — 생성 금지, `unknowns` 로.
- 데이터 부족은 점수가 아니라 **confidence / evidence_coverage 하락**으로 표현된다.
